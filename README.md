# Exercise 1 — Input, Output, and Bitwise Operations

Practice input and output, number bases, and bitwise operations in C. Work with individual bits, complements, rotations, and powers of two without using loops or conditionals.

Start by reading the [Exercise 1 instructions (PDF)](./exercise-1.pdf), then complete the tasks in [`ex1.c`](./ex1.c). Follow the instructions carefully, including the allowed operations and required output format.

If you get stuck, ask in the course forum. Include your operating system, the task or step you reached, and any error message you received.
